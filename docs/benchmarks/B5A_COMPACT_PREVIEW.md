# B5a — компактный предпросмотр района

13 ноября 2026. База разработки — `261f53fb2b73cb56d993b8267ae874e6db6ff872`; измеряется рабочая реализация B5a этого изменения, точные SHA-256 исходников записаны в обоих JSON. applicationRef оставлен null, чтобы не приписывать изменённый код базовому коммиту.

[Полный формат](B5A_FULL.json) · [delta-v1](B5A_DELTA.json) · [Предыдущая I1a](I1A_WORLD_BASELINE.md).

## Метод

Повторён тот же детерминированный стенд I1a: три профиля, отдельный сервер/временная кампания на профиль, один прогрев и пять выборок. Сначала полный формат, затем delta-v1; финальные прогоны выполнены последовательно, без тестов и других профилей одновременно. Оба формата используют один и тот же новый серверный код; исходные хеши совпадают. Старые пилотные прогоны не входят в отчёты.

Среда: v24.22.1, linux 6.18.57, AMD EPYC 7763 64-Core Processor, доступная параллельность 9. I1a выполнялась на другом CPU (EPYC 9V74); сравнивать её 449 мс с новыми значениями как ускорение/регрессию нельзя.

wallMs включает loopback HTTP, получение и JSON-разбор ответа. Восстановление дельты на клиенте измеряется отдельно в expandMs; это Node-клиент, не браузер. p95 ближайшего ранга при пяти выборках равен максимуму. Кеш файлов прогрет, физический диск/FPS/LAN не измерены.

## Память и оставшаяся работа

Пик RSS включает запуск/прогрев/все операции профиля, а не только preview. Ниже значения full → delta, MiB:

- small: 73.2 → 75.5.
- medium: 223.2 → 223.8.
- limit: 301.6 → 320.5.

Улучшение памяти не доказано: на предельном профиле пик выше. Сервер всё ещё читает полный черновик, вычисляет полную генерацию и подписывает два полных снимка. Клиент восстанавливает полные списки для прежних истории/PUT. B5a сокращает транспорт; частичные чтения/записи и память требуют отдельного B5b. Лимиты не повышались, новых зависимостей и миграций нет.

Во всех профилях прошли сохранение/повторная загрузка, проверка объектов/рецептов и неизменность связанного дома/пары. Полный npm test — **70/70**. Браузерная приёмка B5a не выполнена: подключённый Chrome и облачный браузер получили ERR_CONNECTION_REFUSED к изолированному тестовому серверу. Это не отказ приложения в HTTP-тестах. Следующая задача — B5a2, приёмка редактора, до перехода к B5b.

## Повтор

```bash
npm run benchmark:world -- --preview-format full --samples 5 --output /tmp/vtt-b5a-full-new.json
npm run benchmark:world -- --preview-format delta-v1 --samples 5 --output /tmp/vtt-b5a-delta-new.json
```

Выполнять последовательно и выбирать новые пути; существующие отчёты не перезаписываются. По умолчанию стенд использует delta-v1, как редактор. --ref указывайте только для действительно измеряемого чистого коммита; для изменённого checkout оставляйте null и используйте sourceSha256. Сырые строки включают память, CPU, логические файловые чтения/записи, размер запроса и отдельные затраты JSON.stringify/expand.
