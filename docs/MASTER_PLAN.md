## Текущий этап

A0–A3 и B1–B3 завершены. Новые карты хранят чанки отдельно, телевизор читает только запрошенные чанки, API мастера поддерживает частичную запись. Следующая задача B4 — проверяемый импорт прежних JSON с резервной копией, сохранением ID, снимка и тумана, безопасным повторным запуском и проверкой отката.

## Порядок интеграции

Первый игровой срез включает двух героев в одной сцене, стену, дверь, скрытую локацию и три вида экрана. Сначала проверяются серверные проекции и права, затем они подключаются к интерфейсам. Текущие растровые сцены и общий мир продолжают обслуживаться существующими маршрутами, пока новый сценарий проходит проверки.

Приёмка первой версии повторяет сценарий ТЗ с тремя героями и заранее подготовленным миром. Герои расходятся, один делает открытие, мастер отдельно публикует его, редактирует карту во время сессии, затем участники переподключаются и сервер перезапускается. Расширенные генераторы локаций, эффекты и выпуск Windows следуют своим этапам.
