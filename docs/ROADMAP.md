# Универсальная книга мастера

## Текущий этап. Непрерывная карта мира

- [x] Первый единый стиль для «Деревни у озера»: фактуры поверхностей, стыки тропы и берега, кроны леса, дом, таверна и мост. Превью палитры использует те же изображения, что и карта.
- [ ] Следующий набор в этом стиле: интерьер, мебель, смена и закрепление рисунка тайла.

- [x] Вход «Карты → Большая карта мира». Клетки, палитра, прямоугольное заполнение, автоматические стыки троп, воды и леса, отдельный слой готовых объектов.
- [x] Сохранение редактируемого черновика и публикация отдельной версии. Видимый участок рассчитывается по координатам камеры.
- [x] Общая карта в виджете мастера и отдельном окне игроков. Независимое приближение и панорамирование, отдельная отправка кадра и восстановление жетонов после перезапуска.
- [x] Начальный туман. Выбранный участок можно открыть вручную, перемещение жетона открывает клетки в радиусе четырёх клеток.
- [ ] Пройти полную проверку редактора и двух экранов в браузере.
- [ ] Импорт фона и заготовок непосредственно на большое полотно, индивидуальный радиус героев, ручное скрытие и режим предпросмотра.
- [ ] Входы в здания, интерьер поверх улицы и сохранение раздельных групп.

Порядок проверки. «Карты → Большая карта мира», включить «Начать с деревни у озера», создать карту и нажать «Показать игрокам». С открытым туманом поставь героя или открой участок из виджета мастера. Сценарий по API проверяет, что сохранение черновика не меняет показанную карту, скрытая дверь не передаётся, а движение и открытый туман сохраняются после перезапуска.

## 1. Общая карта на втором мониторе

- [x] Карта без входа в персонажа. Полный экран, вписывание карты и восстановление сцены при переподключении.
- [x] Сервер отправляет только данные для игроков, в том числе когда окно открыто из браузера мастера.
- Приёмка: сменить сцену, открыть туман, раскрыть токен и переподключить экран. Телефон игрока продолжает работать.

- [x] Закрыть прямой доступ к редактируемым слоям. Новые слои сохраняются в папке кампании, существующие карты основной игры доступны мастеру через редактор.

- Приёмка: скопировать локацию в новую кампанию, изменить копию и проверить оригинал и данные обеих кампаний.

- [x] Переход в существующую песочницу из раздела «Карты» с сохранением выбранной кампании.
- [ ] Кисть, ластик, заливка, размещение и перемещение объектов. Палитра природных поверхностей, построек и троп. Отмена и повтор.
- [ ] Слои фона, объектов, токенов, тумана и тайных элементов. Черновик, предпросмотр и явная публикация.
