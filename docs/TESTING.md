# Проверки

## Запуск

В полном checkout с Node.js LTS:

```sh
npm ci
npm test
```

Тесты используют `node:test`. `characters.test.cjs` проверяет конструктор героев, `layout.test.cjs` — размещение панелей, `sync.test.cjs` — реальный сервер, HTTP и WebSocket, границы кампаний, права мастера, редактор мира и перезапуск. Интеграционный тест занимает порт 3098, запускает поддельный сервер Ollama и использует временный `DATA_DIR`. Он копирует и создаёт изображения в `public/assets/maps`, поэтому его следует запускать в отдельной рабочей копии. Перед запуском проверьте, что порт свободен.

## Результат A0

Среда аудита — Linux, Node.js 24.22.1. Текстовые файлы и штатные PNG, нужные интеграционному тесту, получены через GitHub и проверены по blob SHA. Исходный набор прошёл 12 из 12 со штатными PNG. Проверка синтаксиса JavaScript прошла. Браузерная отрисовка, содержимое PDF и запуск на Windows в этом прогоне не проверялись.

## Проверки перед последующими этапами

- Перед миграцией на копии остановить сервер и сохранить `DATA_DIR` вместе с `public/assets`. Проверить открытие карт и кампаний из копии, повтор импорта, отказ на частично повреждённых данных и возврат к прежнему формату из резервной копии.
- Для ролей проверять HTTP и WS с гостем, двумя телефонами и телевизором, в том числе при первоначальной загрузке, изменениях и переподключении. Проверять отсутствие скрытых данных в ответах, событиях и доступных ассетах.
- Для тумана проверять отрицательные координаты, границы чанков, этажи, стены, двери, перенос, сохранение после перезапуска и раздельное раскрытие секрета.
- Для LAN запустить мастерский экран и ТВ на компьютере мастера, подключить телефоны, разделить группу и проверить синхронизацию показателей и карт. Зафиксировать устройства, размер мира, нагрузку и метод замера.
