# G1a — кисть местности

15 ноября 2026. База: f7455d39946b126530ca4345e41ab36d17c1e4c2, рабочая ветка codex/audit-and-stabilization. Приоритет пользователя — изменение реального редактора вместо диагностического B5b3m.

## Реализовано

- Кисть покрытия/ластик по удержанию левой кнопки: круг или квадрат, 1/3/5/9/15 кл.
- Подсвеченная область под курсором и настоящее покрытие на предварительном слое во время движения.
- Интерполяция отпечатков при быстрых движениях, без пропущенных промежуточных клеток.
- Один мазок — одна запись Undo/Redo; исходный документ до commit не меняется.
- Escape, pointercancel и потеря захвата отменяют весь мазок; второй указатель его не отменяет.
- Предел 16 384 посещённых клеток и прежние 150 000 тайлов карты; ошибка отменяет весь мазок, без частичной фиксации.
- Прежние ручные правки генераторов, формат/сохранение/публикация. Ластик не удаляет объекты. Прямоугольник рисуется прежними двумя кликами.

## Что проверено

Полный npm test: **129/129**, Node.js 24.22.1, без пропусков; семь изменённых JS прошли node --check. Девять новых сценариев: ядро (4), жесты (1), интеграция редактора (3), настоящий HTTP (1). Регрессия движения объектов и все прежние серверные/VM тесты проходят.

VM использует реальный код dm/world.js с моделью DOM, поэтому проверяет обработчики/историю/защиту генераторов, но не реальное поведение браузера. Настоящий HTTP сохраняет мазок через отрицательные/положительные чанки, открывает его повторно, публикует и читает общий экран без DM cookie. Проверены изоляция опубликованной карты от Undo черновика, повторное сохранение Redo, скрытый сундук и туман. Одноразовая кампания удаляется тестом; пользовательские карты не затронуты.

## Что не проверено

**Живая браузерная приёмка не выполнена.** Подключённый Chrome и облачный Chrome при переходе к http://127.0.0.1:3099/?view=maps получили ERR_CONNECTION_REFUSED. Тестовый сервер, запущенный отдельной командой, недоступен браузерной среде. Это не скриншот/не успешное испытание мышью. Файлы доказательства визуального результата не созданы. FPS, Windows, LAN, телефоны и сенсорный ввод не измерялись.

## Продолжение при доступном локальном браузере

1. Полный checkout ветки, npm ci, затем node scripts/browser-qa.cjs. Открыть напечатанный адрес в браузере, который видит этот сервер. Использовать только созданную одноразовую кампанию.
2. Создать карту с образцом деревни. Выбрать Вода, круг, размер 5; быстро провести изгибающуюся реку. Проверить непрерывное покрытие и совпадение области курсора с мазком.
3. Одно нажатие «Отменить» должно вернуть весь мазок; «Повторить» — восстановить. Сохранить, перезагрузить страницу и открыть карту: покрытие прежнее.
4. Размер 15/квадрат: нарисовать поляну. Ластиком удалить часть покрытия; объекты остаются. Во время нового мазка нажать Escape, проверить полный откат и отсутствие новой записи истории.
5. Выбрать «Заполнить прямоугольник»: кисть не срабатывает, два клика заполняют прямоугольник. Правая кнопка сдвигает карту; выбор/перетаскивание дома прежние.
6. Нарисовать Path/Forest Plot, покрасить часть кистью, изменить seed/параметры генератора: ручной участок сохраняется. Undo/Redo восстанавливают и защиту ручных клеток.
7. Опубликовать без тумана, проверить общий экран; включить туман — неизведанное скрыто. Сохранить свежие кадры редактора/общего экрана и дополнить этот протокол результатами. До этого не считать браузерную приёмку пройденной.
