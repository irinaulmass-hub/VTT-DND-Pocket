# B5b1 — серверное применение района

13 ноября 2026. База — `119a1ed7d52dca31f34a44bdb9e1d439765b9c3a`. Реализован серверный API; редактор и benchmark используют прежний PUT до B5b2.

## Контракт

POST `/api/worlds/:id/district-apply`, авторизованный мастер, тело только `{districtGuard}` (recipe/revision/linksRevision) до 8 KiB. Сервер пересчитывает результат из сохранённого черновика и текущих пар. После обычной валидации существующий writeDraft сохраняет карту; ревизия увеличивается один раз. Возвращаются id/baseRevision/revision, change delta-v1 и HMAC history before/after. Полные chunks/objects/generators не принимаются и не возвращаются верхними полями. Старый PUT и его история остаются совместимыми.

| Автоматический сценарий | Результат |
| --- | --- |
| prepareApply и guarded PUT на одинаковой базе | Совпадают точные chunks/objects/generators и нормализация hidden |
| Восстановление ответа, исходная карта, ручной скрытый объект/грунт | Совпадает с записью; исходник/ручные данные сохранены |
| Неверное тело, лишние поля, неправильный guard/historyProof | 400 до записи |
| Старая карта, перепривязка/удаление пары, исчерпанная ревизия | 409 до записи |
| Гость, игрок, ТВ с cookie мастера | Доступ отклонён |
| Другая кампания | 404 |
| Настоящий POST, повтор запроса и завышенное тело | 200 с одной новой ревизией; повтор 409, тело >8 KiB — 413 |
| Отказы HTTP | Черновик не меняется |
| Связанный дом, список пары и опубликованный экран | Не меняются за пределами разрешённой генерации; нет публикации |
| HMAC-отмена/повтор результата через прежний PUT | Успешны |
| Legacy JSON | Применён без перевода в чанковый формат |
| Перезапуск и вход/точный возврат героя | Пройдены на сохранённом районе |

Полный npm test — **73/73**, Node.js 24.22.1; синтаксис изменённых JS проверен. Тестовый guard-запрос меньше 1 KiB на HTTP-фикстуре; это проверка контракта, не замер задержки огромного мира.

Формат сохранений, лимиты мира, графика и зависимости не менялись. На сервере остаются полное чтение, расчёт/HMAC и запись манифеста. Ускорение UI в B5b1 не заявляется: следующий шаг B5b2 — подключение нового маршрута и проверка согласованной истории, потери ответа, браузера и стенда.
