# Проверка связанных домов F5d2

13 ноября 2026. База — `93e2c756efbc43ce039eeefc3ed527d7a04312c2`, Node.js 24.22.1, Linux, отдельные временные каталоги тестов.

| Сценарий | Результат |
| --- | --- |
| Смена seed и уменьшение числа домов | Связанный дом сохраняет ID/геометрию и учитывается в count |
| Только связанные дома без новых | Расчёт допускается, дубликатов нет |
| Слишком малый count, контур отсекает дом/реальную входную клетку, перенос улицы | 409 без изменения карты/пары |
| Подложка и клетка точного возврата | Удерживаются при регенерации |
| Снятие связи | Дом освобождается, ненужная подложка восстанавливается к исходному грунту |
| Создание/перепривязка/удаление пары после предпросмотра | Старый guard отклоняется |
| Подмена объектов, тайлов или рецепта результата | Пересчёт сервера отклоняет PUT |
| Повтор guard на новой ревизии | Сценарий воспроизвёл ошибку, после исправления даёт 409 |
| Роли и кампании | Только мастер текущей кампании получает полный предпросмотр |
| Перезапуск и опубликованные карты | Герой входит в сохранённый интерьер и возвращается в прежнюю клетку |

Полный набор — **62/62**, новые сценарии модуля — **4/4**, синтаксис изменённых JS проверен. Файл переходов при регенерации не переписывается; guard не сохраняется и не публикуется. Новых библиотек/формата/миграций нет.

Браузерная панель District ещё не добавлена. Следующая задача — F5d3, интерфейс, сохранение перед предпросмотром, применение с guard, история и браузерная приёмка мастера/ТВ. F5d целиком остаётся открытым. Неполную/устаревшую пару или перекрытый вход нужно исправить перед расчётом; изменение любой пары кампании может потребовать новый предпросмотр.
