# G1b — копии и повторная расстановка

15 ноября 2026. База fd22517e341f31067b11ba616b6abc0e51ee3ca9, ветка codex/audit-and-stabilization.

## Реализовано

Выбрать объект инструментом перемещения → «Копировать» (или Ctrl+D на Canvas) → указать место. До клика копия существует только в предпросмотре. R/кнопка поворачивают образец, Esc/«Завершить» отменяют режим без изменения карты. «Ставить несколько» сохраняет образец после каждого клика и работает также при выборе типа из палитры. По умолчанию обычная однократная установка возвращает режим перемещения.

Копия получает новый ID и сохраняет тип, поворот и hidden. При коллизии ID выполняются ограниченные повторные попытки; при лимите 3 000 объект не добавляется. Образец сбрасывается при смене инструмента/карты. Копия не получает владение генератора или переходы исходного дома. Каждый установленный объект — отдельный Undo/Redo с прежней защитой ручных правок. Сервер/схема/лимиты карт/зависимости не менялись.

## Автоматические проверки

Полный npm test — **135/135**, Node.js 24.22.1, без пропусков; синтаксис пяти JS проверен. Шесть новых сценариев (5 редактора, 1 рендера), расширен существующий настоящий HTTP.

- Сохранение kind/turn/hidden и независимость оригинала; предпросмотр без изменения draft/истории.
- Отдельные ID, Ctrl+D/R/Esc, повтор, Undo/Redo/save/reload.
- Лимит/коллизия ID без записи истории; сброс образца при открытии карты/смене инструмента.
- Копия объекта генератора не записывается в его state.objects и остаётся при регенерации.
- Обычная палитра с repeat и однократной установкой.
- WorldView исполняет кадр Canvas-модели: координата/прозрачность/восстановление state/отсутствие записи ghost в data.objects.
- Настоящий HTTP создаёт пару переходов дома в интерьер, сохраняет и перечитывает копию: исходные поля дома прежние с обычной серверной нормализацией, файл переходов побайтово неизменен. Brush, публичный туман и секреты проверены прежними утверждениями.

## Ограничение живой приёмки

**Живая приёмка G1a и G1b не выполнена.** Штатный managed-preview запущен для одноразового browser-qa. Первая попытка выявила несовпадение порта QA с переданным --port 4173; после конкретного исправления старт не завершился из-за relay-readiness timeout. Дальнейшие обходы сети/новое размещение не применялись. Временный scripts.dev восстановлен побайтово, preview остановлен. Новых скриншотов нет; VM не выдаётся за реальный браузер, FPS/Windows/LAN/сенсорный ввод не заявляются.

Предыдущий план требовал браузерную приёмку перед расширением G1. По текущему поручению продолжен один ограниченный автоматически проверяемый срез; приёмка сохранена как обязательная перед выпуском G1, а не объявлена пройденной.

## Когда среда снова доступна

1. В одноразовой кампании выполнить [проверки кисти G1a](G1A_TERRAIN_BRUSH.md).
2. Выбрать дом, создать одну копию, затем несколько повёрнутых копий. Сверить положение ghost с кликом и видом после установки, включая отрицательные координаты, zoom и правый pan.
3. Проверить Ctrl+D/R/Esc на Canvas, кнопку «Завершить», checkbox repeat и скрытые образцы. Ввод в текстовых полях не должен запускать горячие клавиши.
4. Undo/Redo по одному объекту; сохранить/перезагрузить и открыть карту. Временно начать копию, затем открыть другую карту: старого образца нет.
5. Для связанного дома проверить вход/возврат у исходника; у копии нет автоматически созданной пары. Копию при необходимости привязать отдельно прежним интерфейсом.
6. Проверить лимит, публикацию/туман/скрытость, реальные видимые состояния и сохранить свежие кадры. До этого не закрывать общий браузерный долг G1.
