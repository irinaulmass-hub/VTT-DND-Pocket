# Приёмка интерьера V3a

13 ноября 2026. База — `dc5dfd46abba99dd3f55f363916e06f1f59880bb`. Chromium на Linux, одноразовый DATA_DIR `scripts/browser-qa.cjs`, сцена «Интерьер · Мебель и свет». Пользовательские кампании не использовались.

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Открытие меблированного Room | Видны пол, стены, вход, лестница, кровати, стол, скамейка, сундук и огонь; согласованы материалы и масштаб |
| Библиотека → Кровать → свободная клетка | Появился новый предмет, выделение сообщает 1×2 клетки |
| Поворот, Undo, Redo | Размер меняется на 2×1, возвращается к 1×2 и снова к 2×1 |
| Сохранение и перезагрузка страницы | После повторного открытия повернутая добавленная кровать сохраняется |
| Публикация с выключенным туманом | Общий экран показывает все предметы; при приближении читаются подушка, одеяло, дерево и ступени |
| Публикация с включённым туманом без исследования | Комната и декоративное свечение полностью скрыты |
| Повторное выключение тумана и публикация | На ТВ снова виден сохранённый интерьер |

Полный набор: **54 из 54**. Автоматические тесты отдельно проверили проходимость footprint для четырёх поворотов, обзор поверх мебели, проход по лестнице, воду, сохранение после перезапуска сервера, публикацию предметов и восстановление Canvas-трансформаций.

Лестница пока не создаёт переход автоматически. Свет статический и декоративный, правил освещения D&D нет. Физические устройства и Windows не проверялись. Следующая задача — F5d, небольшой District Plot с домами и улицами.
