# F6a — редактируемые контуры

База: `0bf5457`, ветка `codex/world-contours`. Node.js 24.22.1, Chrome/Linux, 15 ноября 2026.

## Проверено автоматически

`npm test`: 150 тестов, 150 успешно, 0 ошибок/пропусков.

- Ядро геометрии: независимость исходных точек, отрицательные координаты, середины рёбер, удаление, пересечения/повторения/лимиты.
- Room: соседние стороны по сетке, перенос входа вместе со стеной, отдельный перенос двери, отказ на углу/вырожденном помещении. District: прямоугольник и прежние пределы.
- Редактор: временный drag/cancel, координаты, история точек, применение прежнего ID, Undo/Redo карты, сохранение/загрузка.
- Canvas: экранное расстояние независимо от сдвига панели, чужой указатель, Escape/потеря захвата, линии/заливка/номера/вход.
- Прежние серверные HTTP/WS, конфликты District, ручные исключения, туман и права входят в полный набор и проходят. Формат сохранений и серверные маршруты не изменены.

## Проверено в браузере

Использован `scripts/browser-qa.cjs`, отдельные временные DATA_DIR, порты 3199/3200. Сервер запущен через терминал тестового рабочего стола: localhost обычного exec не доступен браузеру.

1. Открыт черновик внешней сцены. Новая боковая библиотека и большое поле видны. Path из трёх точек отображается; средняя вершина перетаскивается.
2. Изменена ширина до 3, выполнены предпросмотр, применение, сохранение, отмена и повтор применения, повторное сохранение.
3. Открыта готовая Room, загружен её рецепт. Перетаскивание угла проверено мышью. В финальном повторе точные координаты угла заданы как (-2,-1), вход автоматически стал (2,-1).
4. Вход выбран отдельно и перенесён в (6,3). Применена регенерация; получено «Черновик сохранён».
5. Страница перезагружена, снова открыты карта и рецепт. DOM полей: X=-2, Y=-1, текст «Вход: 6, 3». Сохранение подтверждено через интерфейс.

## Границы результата

- Новых спрайтов, ассетов, вариантов реквизита и автоматической мебели нет. Существующая графика сохранена.
- Room/District: перенос углов, без вставки/удаления углов. Сложные вогнутые помещения допускаются только при сохранении существующих ограничений геометрии.
- Path остаётся линией по опорным точкам; сглаженные кривые и генерация стен/заборов — следующая работа.
- Forest/District с новым drag проверены автоматически, отдельная новая ручная приёмка этих двух инструментов не заявляется.
- Физические телефоны, ТВ, LAN, Windows и FPS заново не проверены.
