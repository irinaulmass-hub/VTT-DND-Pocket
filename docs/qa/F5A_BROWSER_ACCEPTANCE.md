# Браузерная приёмка F4/F5a

Дата: 13 ноября 2026. Среда: Chromium на Linux, Node.js 24.22.1, настоящий сервер приложения и Canvas. Только отдельная временная кампания, созданная для проверки. База: `aab84fcb85a5e0eea6b34a3681980a36f8d9ad23`; проверялось также исправление обновления кнопок в `run().finally`.

## Стенд

Обычный запуск команд и браузер находились в разных сетевых средах; это объясняет прежний ERR_CONNECTION_REFUSED. Каталог исходников общий. Сервер запущен из терминала в среде браузера. `scripts/browser-qa.cjs` создаёт временные данные и одноразовую мастерскую сессию через штатный HTTP-вход. Loopback-прокси передаёт её в HTTP и WS. Авторизация разных ролей проверяется отдельно на штатном сервере автоматическими тестами.

## Исправление по результатам приёмки

После сохранения изменённого черновика «Сохранить настройки» оставалась disabled: `save()` вызывал `paint()` при `busy=true`, а `run()` снимал busy без обновления кнопок. Обновление вынесено в `finally` после снятия блокировки. Регрессионный тест сначала упал на прежнем коде. После исправления тест прошёл, а браузер подтвердил доступность и успешное сохранение шаблона сразу после PUT карты.

## Границы результата

F5a завершена для текущего мастерского интерфейса. Графика V1 сохранена. Эта проверка не измеряет 60 FPS, задержку LAN и пределы огромного мира и не подтверждает работу физических телефонов/ТВ или Windows. Следующая задача — F5b, генератор одной комнаты.
