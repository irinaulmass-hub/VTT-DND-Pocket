# Проект «днд» — VTT-DND-Pocket

## Автоматическое продолжение

По команде «Продолжай» прочитать актуальные `docs/MASTER_PLAN.md`, `docs/DEVELOPMENT_PROGRESS.md` и последние коммиты, выбрать следующую невыполненную задачу, реализовать её, проверить тестами и исправить ошибки. Обновить оба документа, сохранить результат в Git и предоставить краткий отчёт со следующим шагом.

Не просить повторять инструкции или выбирать очередную задачу. В новом чате восстанавливать контекст из документации репозитория. Останавливаться при необходимости решения пользователя, опасных изменениях или завершении текущего поручения.

Если запись в GitHub недоступна, сохранить локальный коммит и передать архив с патчем, изменёнными файлами и инструкцией для другого чата. Указать базовый коммит и результаты проверок. До следующей задачи сверять, применён ли предыдущий пакет; локальный результат не выдавать за опубликованный в GitHub.

## Источники контекста

- План: `docs/MASTER_PLAN.md`.
- Фактический прогресс: `docs/DEVELOPMENT_PROGRESS.md`.
- Проверки: `docs/TESTING.md`; стандартные команды — `npm ci` и `npm test`.
- Перед работой определить актуальную ветку по открытому PR и последним коммитам. `main` может отставать. На момент F4 рабочая ветка — `codex/audit-and-stabilization`, PR #1.
- Canvas of Kings — ориентир для всей карты: местность, постройки, укрепления, интерьеры, подземелья, мебель, реквизит и существа. Использовать собственную графику с единым направлением теней.
- Сохранять чужие изменения и пользовательские данные. Для интеграции пакета сначала проверять его базу и конфликты.
