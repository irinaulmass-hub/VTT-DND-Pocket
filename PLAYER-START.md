# Карманная карточка DnD

Дважды нажмите ярлык **VTT - DnD** на рабочем столе. Откроется мастерская панель; сервер работает в фоне, окно терминала не нужно. Повторное нажатие открывает панель и не запускает второй сервер.

Пароль мастера из исходного проекта: **dm1234**. Его можно изменить переменной окружения `DM_PASSWORD` перед запуском сервера.

В панели откройте **📱 Подключить игроков** справа внизу. Передайте игрокам указанный адрес с `/player`, а на телевизоре откройте адрес с `/tv`. Все устройства должны находиться в одной локальной сети. Если Windows предложит разрешить Node.js доступ к частной сети, разрешите его для игры по Wi-Fi.

Игрок выбирает персонажа один раз. Выбор сохраняется на телефоне. Четыре раздела: Персонаж, Инвентарь, Умения, Бой. HP, затмение, предметы, ячейки и состояния обновляются автоматически; после потери сети карточка переподключается.

В мастерской панели на листе персонажа нажмите **Карточка игрока · изменить**. HP и ячейки можно менять прежними кнопками. Боевые данные и инвентарь редактируются здесь же. Изменять карточки могут только пользователи, вошедшие как мастер. Доступ игрока — просмотр; аккаунты не нужны. Любой участник локальной сети может выбрать любую карточку.

Сервер хранит изменения в `data/characters.json`. Папка `data` и журналы запуска не попадают в Git. Начальные персонажи находятся в `seeds/characters.json`.

Для переноса на другой компьютер: установите Node.js, выполните `npm ci` в папке проекта, затем запустите `Create-Shortcut.ps1`. Для обычной игры терминал больше не нужен.

Проверка синхронизации: `npm test`.
